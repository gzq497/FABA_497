# Attribution and licensing

This framework contains existing upstream research code and preserves its
attribution comments (including the FedMultimodal code attribution) and bundled
license/readme files. Keep these notices with derived distributions. Source
comments and method names are not a substitute for a license grant.

No new blanket license is assigned to the combined repository. Confirm the
applicable permissions for each upstream component when publishing; retain any
additional upstream licenses required for your distribution. No repository
history or author identity is fabricated by this packaging process.

External data and pretrained weights remain governed by their providers' terms.
The source-owned `attacks/badcm/assets/pattern.jpg` is retained as a runtime asset.
Downloaded model checkpoints and dataset content are not redistributed.
